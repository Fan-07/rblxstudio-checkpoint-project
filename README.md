# rblxstudio-checkpoint-project
an extensive code for the functionality of simplistic checkpoint system customizable with name changes

|| IMPORTANT MUST READ ||

must not already have a part in the workspace named "checkpoint_(number)") (number as in actual numbers)

1) insert a "Checkpoint_1" part and to that, add a "Spawn" part. these will act as your initial checkpoint
2) in GameGUI, add a text label with the text "Checkpoint 0". you can design it however you wish
3) in the textlabel, add a local script and insert the script acquired from the checkpointguiupdate file
4) you can then copy the "Checkpoint_1" part however many times you want and rename it to "Checkpoint_2", "Checkpoint_3" for the 2nd 3rd checkpoint, etc
5) your checkpoints are updated both on the textlabel and leaderboard

read the code comments to clear your doubts
